# 🍂 运河漫步 · 小猫与阿尔瓦的秋日散步 (Leiden Canal Cat Walk)

> **版本**：v2.1.0 (模块化解耦与衣橱系统重构版)  
> **运行方式**：直接在现代浏览器中双击打开 `cat_walk_index.html` 即可运行。

---

## 📁 目录与文件架构拆分说明

为了避免代码冗长堆叠，方便随时增补台词文案与成就设定，现已将项目全面重构拆分为三大模块：

```text
├── cat_walk_dialogues.js    # 💬 文案与配置数据源（独立解耦，猫猫随时可改）
├── cat_walk_index.html      # 🎨 核心游戏主程序（像素画布、渲染管线、物理与交互）
├── README.md                # 📖 项目架构、文案拓展规范与快捷键指南
└── cat_white.png            # 🖼️ 猫咪像素精灵切片表 (Sprite Sheet)
```

### 1. `cat_walk_dialogues.js`（独立文案与内容配置文件）
**后面小猫想改文案、加台词，直接打开这个文件改即可，完全不需要动复杂的画布与逻辑代码！**
- `window.CatWalkDialogues.hermanDialogues`: 长椅上赫尔曼的常态碎碎念台词。
- `window.CatWalkDialogues.alvaDialogues`: 阿尔瓦递拿铁、揉耳尖的温柔互动台词。
- `window.CatWalkDialogues.scratchDialogues`: 普通形态抓挠赫尔曼的趣味反应。
- `window.CatWalkDialogues.bossScratchDialogues`: 击打 500HP 黄金赫尔曼时的金属火花对话。
- `window.CatWalkDialogues.diamondScratchDialogues`: 击打 1000HP 钻石赫尔曼时的七彩折射对话。
- `window.CatWalkDialogues.catMeows`: 小猫按空格或主动喵喵叫的台词。
- `window.CatWalkDialogues.getFlavorText(stats)`: 手帐顶部根据战绩动态变化的温馨评语。
- `window.CatWalkDialogues.achievementsList`: 成就体系定义列表（门槛判定、图标、说明与奖励）。
- `window.CatWalkDialogues.wardrobeItems`: 🎒 独立衣橱与道具库（黄金领结、钻石领结、纯钻皇冠、白手帕、焦糖华夫饼等）。

### 2. `cat_walk_index.html`（核心渲染与交互引擎）
- **像素渲染管线**：支持 320×180 经典低像素怀旧画风，适配 Retina 高清平滑点阵（`image-rendering: pixelated`）。
- **小猫精密锚点系统**：
  - 朝向右（正向）：领结锚点 `(x + 13, y + 17)`
  - 朝向左（翻转）：领结锚点 `(x + 15, y + 17)`
  - 小王冠佩戴：头顶 `(x + 13, y + 6)`
  - 动态摆动与侧身行走完全严丝合缝，绝不漂移悬浮。
- **🎒 漫步手帐与衣橱交互面板**：
  - 支持快捷键 `T` 或 `I`、或点击右下角浮动按钮随时呼出。
  - **自由穿戴/卸下**：在衣橱中点击已解锁的领结或小王冠，即可随时换装！
  - **点击道具**：白手帕可擦拭肉垫，焦糖华夫饼点击可香甜食用并冒出对话框。

## 🎮 操作指南

| 键位 / 操作 | 动作功能说明 |
| :--- | :--- |
| `A` / `D` 或 `←` / `→` | 小猫左右灵动漫步 |
| `W` / `↑` / `Space` | 小猫轻盈起跳 |
| `J` 或点击赫尔曼 | 亮爪抓挠赫尔曼！击碎西服与算力装甲 |
| `K` 或 `Space` | 喵喵叫并冒出头顶气泡台词 |
| `E` | 与场景中的阿尔瓦、赫尔曼或落叶温暖互动 |
| `T` 或 `I` | 随时呼出 / 关闭【🐾 小猫漫步手帐与衣橱背包】 |
| 鼠标点击衣橱卡片 | 自由穿上/取下领结、王冠，或食用特制华夫饼 |

## 💡 后续想要加台词/新道具怎么办？
打开 `cat_walk_dialogues.js`：
- 在对应的数组末尾加上一行 `"你的新台词内容",`
- 保存后刷新网页，立即生效！
