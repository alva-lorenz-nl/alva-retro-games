# 🎮 莱顿复古像素小游戏合集 (Leiden Retro Games)

本仓库收录了莱顿大学与永动轮时期为背景制作的复古像素互动小游戏及问候贺卡。用户通过控制小白猫在像素场景中漫步，探索不同房间、触发互动事件与人物对话。

---

## 目录与场景架构

### 1. 核心探索游戏：`leiden_campus(3).html`（莱顿大学 · 漫步）
- **主角操控**：一只可爱温顺的白猫（方向键或 WASD 移动，空格键或触摸屏幕对话/交互）。
- **瓦片规格**：20 列 × 13 行（Tile: 32px，自适应缩放与暗角氛围光效）。
- **场景与建筑结构**：
  1. **莱顿 · 庭院 (`yard`)**：
     - 包含草坪、庭院石路与绿树。
     - **左侧建筑大门**：通往 **电气与算力实验室 (`lab`)**。
     - **右侧建筑大门**：通往 **古老天文台 (`obs`)**。
  2. **电气与算力实验室 (`lab`)**：
     - 主厅布局，配备黑板、黑白机架与工作桌。
     - **NPC 赫尔曼·塞曼**：年轻时执着于算法收敛与“永动机”构想，对溜进来的白猫格外温和。
     - **NPC 阿尔瓦·洛伦兹**：推着单边眼镜在图纸间伏案，默默替赫尔曼披衣、留意他的作息。
     - **内部门道**：
       - 通往 **实验台 (`lab_bench`)**：展示烧杯、沉淀记忆与威士忌酒杯的熬夜痕迹。
       - 通往 **藏书间 (`lab_shelf`)**：高书架与《物理评论》旧期刊合订本，藏着百年前跨越时空的笔注。
       - 南侧大门：返回庭院。
  3. **古老天文台 (`obs`)**：
     - 拥有十九世纪手磨赤道仪圆顶。
     - **NPC 对话**：赫尔曼热忱讲解赤道仪结构，阿尔瓦在冷风中静静倾听并为他整理衣领。

## 关键代码模块索引（以 `leiden_campus(3).html` 为例）

1. **渲染与画布引擎**：
   - `fit()`: 窗口等比缩放、像素整数倍对齐，保证像素风清晰不虚化。
   - `drawSky()`, `drawFloor()`, `drawProps()`: 地图与背景道具图层绘制。
   - `drawCat()`, `drawNPC()`: 动态白猫帧动画及人物外观（赫尔曼棕发绿衣、阿尔瓦灰白发与单边眼镜）。
   - `drawVignette()`: 电影感复古暗角与光影烘托。

2. **碰撞检测与移动系统**：
   - `solidChars`: 障碍物瓦片集合（墙体 `#`、桌子 `T`、书架 `S`、仪器 `C` 等）。
   - `solid(sc, c, r)`: 场景边界及阻挡逻辑。
   - `moveAxis()`: 角色平滑移动与滑动碰撞处理。

3. **场景切换与门禁逻辑**：
   - `doors[]`: 包含 `to`（目标场景标识符）、`spawn`（传达后出生坐标）、`exit` 标识。
   - `enter(name)`: 场景切换、NPC 重新绑定与标题淡入。

4. **文本与对话框系统**：
   - `interact()`: 检测白猫朝向与邻近 NPC/交互物。
   - `renderLine()`, `advance()`: 逐句展开对话与气泡过渡。
